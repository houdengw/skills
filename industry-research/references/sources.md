# 信息源清单

按可信度和使用价值排序。不能联网时，在报告中告诉用户应该去哪些地方核实。

## 一、上市公司一手披露（最推荐的入门资料）

| 来源 | 用途 | 获取途径 |
|---|---|---|
| **招股说明书** | 小白入门产业的最佳教材。"业务与技术"章节会系统介绍行业概况、产业链、竞争格局、主要竞争对手和自身的市场地位 | 巨潮资讯网、上交所/深交所/北交所官网、港交所披露易、SEC EDGAR |
| **交易所问询函及回复** | 监管机构会追问公司的行业地位、市场份额、毛利率差异等关键问题，回答往往比招股书更直接 | 交易所官网"审核动态"或"监管信息公开" |
| **年报、半年报** | 财务数据、经营数据、"管理层讨论与分析"中的行业判断 | 同上 |
| **投资者关系活动记录表** | 管理层对行业趋势、订单、价格的最新判断 | 深交所互动易、上证 e 互动、巨潮资讯 |
| **业绩说明会、海外公司财报电话会** | 龙头企业对行业需求的判断，通常比较前瞻 | 公司官网、IR 页面 |

**使用技巧**：先找产业链各环节 2–3 家代表性上市公司，读它们的招股书行业章节，再对比它们的财务数据，就能快速搭出产业链和利润分布的框架。

## 二、官方统计与政策

| 来源 | 用途 |
|---|---|
| 国家统计局 | 宏观数据、工业产品产量、行业数据 |
| 海关总署 | 进出口数据（判断国产化率、海外需求的重要来源） |
| 工信部、发改委、国务院及各部委 | 产业政策、规划、准入目录 |
| 地方政府产业规划 | 地方产业布局和扶持政策 |
| 国家药监局、医保局 | 医药产业：审批、医保目录、集采结果 |
| 国家知识产权局、专利数据库 | 技术路线、研发活跃度 |

## 三、行业协会与第三方机构

| 来源 | 用途 | 注意 |
|---|---|---|
| 各行业协会（如中国汽车工业协会、中国光伏行业协会、中国半导体行业协会） | 行业统计数据、年度报告 | 协会有推动行业发展的立场，预测数据可能偏乐观 |
| 国际机构（如 IEA、SEMI、WSTS、Gartner、IDC） | 全球市场数据 | 部分付费，公开摘要也有价值 |
| 咨询公司（如弗若斯特沙利文、灼识咨询） | 市场规模数据，常被招股书引用 | 由拟上市公司委托撰写时，数据可能偏向委托方 |

## 四、券商研报

- 用途：快速了解市场主流观点、产业链梳理、市场空间测算、公司对比。
- 获取：东方财富网研报中心、萝卜投研、慧博投研、发现报告等（部分免费）。
- **注意**：研报观点普遍偏乐观；同一数据经过多份研报互相引用，可能已经失去原始出处。要尽量追溯到一手来源。
- 比较好的用法：先读 2–3 篇行业深度报告了解框架，再用一手资料核实关键数据。

## 五、付费数据库（如果用户有权限）

Wind、同花顺 iFinD、Choice、彭博、CEIC、SMM（有色金属）、百川盈孚（化工）、鑫椤资讯（锂电）、集邦咨询（半导体、面板）等。

## 六、其他补充来源

| 来源 | 用途 |
|---|---|
| 招投标网站（中国政府采购网、各地公共资源交易中心） | 判断真实需求、中标价格、客户和竞争对手 |
| 企查查、天眼查 | 企业股权结构、融资历程、关联关系 |
| 一级市场融资数据（如 IT 桔子、烯牛数据） | 新兴产业的资本热度、主要创业公司 |
| 招聘网站 | 企业扩张方向、技术方向 |
| 专家访谈、行业纪要 | 获取非公开的一线信息（需要注意合规） |
| 行业展会、技术论坛 | 了解技术进展、新产品 |

## 七、来源可信度判断

引用数据时，按以下顺序判断可信度（从高到低）：

1. 法定披露文件（招股书、年报）、官方统计
2. 行业协会统计数据（历史数据）
3. 国际权威机构数据
4. 券商研报、咨询公司报告
5. 新闻报道、自媒体文章

如果只能找到第 4、5 类来源，要在报告中明确说明，并标注为【待核实】。
