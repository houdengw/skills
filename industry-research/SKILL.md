# 产业研究

## 这个 skill 解决什么问题

用户典型处境：上级甩来一个产业名称或某个产业环节，用户对它不熟，需要在较短时间内交出一份**有结构、有数据、有判断**的产业研究报告，用于投资决策或内部研究。

所以目标不是"写一篇关于这个行业的文章"，而是：

1. **搭出骨架**：用一套固定的分析框架，保证不漏掉关键维度；
2. **填上证据**：每个关键结论都有可追溯的数据和来源；
3. **给出判断**：最后要落到"所以呢"，也就是利润在哪、机会在哪、风险在哪、该盯什么指标；
4. **让用户学会**：用户下次面对另一个产业时也能自己套用这套框架，而不是只拿到一份看不懂来龙去脉的报告。

## 工作流程

### 第 0 步：明确任务（最多问 2–3 个问题，能推断的就不问）

开工前先确认以下几点。用户已经说明的、或者可以从上下文合理推断的，就直接采用，并在报告开头的"研究范围与口径"里写明：

| 要素 | 默认值（用户没说时） |
|---|---|
| 研究对象是整个产业，还是某个环节 | 按用户给的名称判断；如果是环节，仍需简要交代它在整条产业链中的位置 |
| 用途：投资决策 / 研究报告 / 快速了解 | 投资决策 |
| 深度：速览版 / 完整版 | 完整版；用户说"快速""先看看"时用速览版 |
| 地域 | 以中国市场为主，配合全球格局和海外对标 |
| 有没有用户提供的资料（研报、纪要、数据） | 有就优先使用，并与公开信息交叉验证 |

如果用户只给了一个产业名，就不要再追问，按默认值直接开工。问太多问题会拖慢进度，而且小白往往也答不上来。

### 第 1 步：界定研究对象

很多报告一开始就做错了，原因是没定义清楚"这个产业到底指什么"。所以先回答：

- 这个产业或环节的**标准定义**是什么？有没有官方分类（如国民经济行业分类、申万行业分类）？
- **边界和口径**：包括哪些细分，不包括哪些？不同机构统计的市场规模为什么差好几倍（通常是口径不同）？
- 用一句大白话说清楚：**这个产业靠什么赚钱、为谁解决什么问题**。

### 第 2 步：按框架展开分析

按照 `references/framework.md` 中的八个模块逐一分析。**开始分析前先读这个文件**，里面有每个模块的核心问题、关键指标和"对投资意味着什么"。

八个模块概览：

1. 产业定义与边界
2. 产业链结构与价值分布（上中下游、利润池在哪）
3. 市场空间与增长驱动（规模、增速、驱动因素、天花板）
4. 竞争格局（集中度、主要玩家、壁垒、国产化率）
5. 商业模式与财务特征（毛利率、成本结构、资本开支、现金流）
6. 产业阶段与周期（生命周期、技术路线、周期性）
7. 政策与外部环境
8. 关键变量、风险与跟踪指标

不同类型的产业，侧重点和关键指标差别很大（比如周期品看供需和价格，创新药看管线和临床数据，软件看留存和净收入留存率）。所以先判断产业类型，再读 `references/industry-types.md` 中对应的部分来调整分析重点。

### 第 3 步：收集和核实数据

按 `references/sources.md` 中的信息源清单检索。核心原则：

- **一手资料优先**：上市公司招股说明书、年报和交易所问询回复，是小白入门一个产业最好的教材。它们会系统介绍行业、竞争对手和自身的财务数据，而且有法律责任约束，可信度高。
- **关键数字至少交叉验证两个来源**。来源之间矛盾时不要随便挑一个，要把分歧和可能的口径差异写出来。
- 每个数字都写清楚**来源、时间、口径**。

### 第 4 步：形成判断

框架和数据都是为了支撑判断。报告最后必须回答：

- 这个产业**现在处于什么阶段**？未来 3–5 年最核心的变化是什么？
- 产业链上**哪个环节利润最好、最确定**？哪个环节弹性最大？
- 这个产业**最关键的 2–3 个变量**是什么？这些变量往哪个方向变，结论就会被推翻？
- 应该**持续跟踪哪些指标**，以及去哪里找这些数据？

判断要明确，但要和证据强度相匹配。证据不足时直接写"目前证据不足以判断"，并说明还缺什么，这比一个看起来很自信的错误结论有用得多。

### 第 5 步：按模板输出报告

使用 `references/report-template.md` 中的结构输出。速览版和完整版的差别也写在那里。

## 数据纪律（这是本 skill 最重要的部分）

产业报告里最危险的是**看起来很精确、其实是编出来的数字**。小白读者没有能力识别，而它会直接影响投资决策。所以：

- **不编造数字。** 查不到可靠数据时，写成"【待核实】约 XX 量级，依据：……"，或者直接写"未找到可靠公开数据"，并说明可以去哪里找。不要为了让报告看起来完整，就填上一个似是而非的数字。
- **区分三类陈述**，在报告中用标记区分：
  - 【事实】有明确来源的数据或事件；
  - 【推断】基于事实的分析和推理，要写出推理链；
  - 【假设】预测或情景假设，要写出关键假设参数。
- **标注时效**。产业变化快，两年前的市场规模和格局可能已经完全不同。数据较旧时，要提醒读者。
- **注意利益相关方的偏差**。行业协会、上市公司宣传、券商研报都有各自的立场，引用时要意识到这一点，必要时在报告中注明。
- **不能联网时**，明确告诉用户：报告基于训练数据中的知识，有截止日期，所有数字都需要核实。此时报告更像一份"研究框架 + 待核实清单"，要把重点放在框架和需要回答的问题上。

## 帮助用户学会

用户的长期目标是自己掌握这套方法。所以在报告末尾附一个简短的"方法复盘"：

- 这个产业里，哪个分析模块最关键？为什么？
- 这次研究中最有价值的 2–3 个信息源是什么？
- 如果要继续深入，下一步该看什么、访谈谁、问什么问题？

篇幅控制在半页以内，不要变成说教。
