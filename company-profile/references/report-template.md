# 报告模板

## 结构

先结论后细节。每条事实只在它的归属章节展开一次。

```markdown
# [登记全称]企业画像

> 统一社会信用代码：[ ] ｜ 上市代码：[ ] ｜ 报告用途：[ ]
> 数据截至：[最新证据日期] ｜ 生成日期：[ ]
> 来源构成：{{来源构成}}
> 标注说明：【待核实】表示只有低等级来源或口径不明；"据此判断"开头的句子是分析判断，不是事实陈述。

## 一、核心结论
[5–8 条，每条一句话，先给结论再给关键数字，每条带引用。读者只读这一节也能知道这家公司的基本面和最值得注意的事。]

## 二、工商与股权
[基本信息表：全称、信用代码、成立日期、注册资本（写时点）、法定代表人、注册地、企业类型、登记状态、曾用名]
[股权结构：前几大股东及比例、实际控制人或控股股东集团；上市公司用最新披露]
[主要子公司（与主营相关的）]

## 三、主营业务与商业模式
[一段话说清楚卖什么、卖给谁、怎么收钱]
[产品或业务线：每条写清是什么、面向谁、交付方式，有收入数据时附收入]
[客户结构：客户类型、集中度、代表客户（有公开来源时）]

## 四、技术与研发
[技术路线和核心能力]
[研发投入、研发人员（写时点和口径）]
[知识产权：专利、软著、商标，写明是注册授权还是公开申请、统计时点]
[外部评价：第三方评测、奖项，写明是谁的评价]

## 五、经营与财务
[财务表：收入、毛利、净利润或亏损、研发开支等，写明报告期和口径]
来源：[E…]
[收入结构、增长驱动、盈利情况、现金状况]
[非上市企业没有财务披露时，写明"未披露"，可以写能查到的经营指标（中标金额、员工规模变化），但不要估算财务数据]

## 六、融资与资本
[融资轮次表：时间、轮次、金额、投资方、估值（有来源时）]
来源：[E…]
[上市进程、资本运作]

## 七、团队
[员工规模及变化（只写总量和结构，研发占比等已在第四节的不再重复）]
[核心管理层：姓名、职务、背景，每人两三句]

## 八、市场生态与合作
[政府对接：签约、走访、扶持政策、中标的政府项目]
[产学研合作]
[产业合作：上下游伙伴、合资、战略投资]

## 九、风险与关注点
[司法风险：诉讼、被执行、失信]
[行政处罚、监管问询]
[经营风险：持续亏损、客户集中、依赖单一供应商等，有来源支持的才写]
[负面舆情（只写有权威来源的）]
[查过但没有发现的，也写一句"截至××，在××未检索到××"]

## 十、信息缺口与数据冲突
[缺口：哪些内容没查到，查过哪里，可以去哪里补]
[冲突：哪些数字来源之间不一致，各自口径，采用了哪个及理由]
```

参考来源由 `check_report.py render` 自动生成，草稿中不要写。

## 按用途调整

核心结论的选取和各章篇幅按用途调整。章节结构保持不变，这样不同企业的报告可以对比。

| 用途 | 重点章节 | 核心结论里要回答 |
|---|---|---|
| 通用画像 | 均衡 | 这家公司是做什么的、规模多大、处在什么阶段、最值得注意的事 |
| 招商 | 一、三、六、八 | 是否在扩张（融资、新业务、新产能、招聘）；在外地已有哪些落地；对地方能带来什么（产业链、就业、税收），哪些是有依据的，哪些是推断 |
| 投资 | 三、四、五、六、九 | 增长质量、盈利路径、估值与融资历史、主要风险 |
| 合作 | 三、四、八 | 能力边界、真实客户案例、合作方式、已有合作伙伴 |
| 授信 | 二、五、九 | 股权与实控人、偿债能力、现金流、司法与处罚、股权出质 |
| 拜访准备 | 一、三、七、八 | 关键人物背景、近期动态、可以聊的切入点 |

## 篇幅

- 上市公司或信息充分的企业：每章 2–4 段，全文 6000–10000 字。
- 信息少的企业：哪章没有可靠信息就写短，在第十节说明。**不要用行业通论凑篇幅。**
- 一段话只讲一件事，段首用加粗短语点明主题。

## 写法示例

**数字与引用**

- ✗ 公司收入连续三年翻倍，增长迅猛，处于行业领先地位。
- ✓ 2022–2024 年收入分别为 0.57 亿元、1.25 亿元和 3.12 亿元[E004]，2025 年为 7.24 亿元，同比增长 131.9%[E011]。

**派生计算**

- ✗ 持股员工占员工总数的 51.2%[E040][E041]。（分子 451 人包含顾问，分母 883 人只是员工，口径不一致）
- ✓ 两个员工持股平台合计覆盖 451 名员工及顾问[E040]，同期员工总数为 883 人[E041]。

**评价性措辞**

- ✗ 公司稳居国内大模型第一梯队。
- ✓ 据弗若斯特沙利文（招股书引用），按 2024 年收入计，公司在中国独立通用大模型开发商中排名第一[E006]。

**来源冲突**

- ✓ 专利数量口径不一：招股书称在中国拥有 86 项注册专利、另有 234 项申请[E022]；企业信息平台显示公开专利信息 269 条[E023]。差异主要来自"注册授权"与"公开申请"的口径不同，本报告采用招股书口径。

**判断**

- ✓ 据此判断，公司收入仍以本地化部署为主，云端 API 增长快但基数小，依据是第五节的收入结构表。

**信息缺口**

- ✓ 截至 2026 年 10 月，未在公开渠道检索到公司 2026 年中期的分业务收入，已查港交所披露易和公司官网。
