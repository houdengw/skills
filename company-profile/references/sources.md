# 信息源与来源分级

## 来源分级

每条证据都要标等级。等级决定它能支撑什么样的结论。

| 等级 | 包括 | 能支撑什么 |
|---|---|---|
| **T1** 法定披露与官方登记 | 招股书、年报、中报、交易所公告和问询回复；国家企业信用信息公示系统；裁判文书网、执行信息公开网；国家知识产权局；政府采购网的中标公告；公司官网的正式公告 | 任何事实，包括关键数字 |
| **T2** 政府、监管、权威媒体与机构 | 政府、园区官网的新闻；监管机构发布；新华社、人民日报、财新、第一财经、证券时报、上海证券报、中国证券报、经济观察报、21 世纪经济报道等；大学官网；企查查、天眼查等企业信息平台上的工商字段 | 任何事实；关键数字最好再有 T1 印证 |
| **T3** 行业媒体与研究机构 | 36 氪、虎嗅、钛媒体、界面等科技财经媒体；券商研报；咨询机构报告；行业协会 | 业务、产品、动态；数字要写明出处并尽量追溯到 T1 |
| **T4** 自媒体、百科、论坛 | 雪球、头条号、知乎、CSDN、搜狐号、百家号、东方财富财富号与股吧、百度百科、各类聚合站 | 只能作为线索。正文引用时要标【待核实】，或者顺着它找到原始来源 |

**不收录**：其他 AI 产品生成的内容（AI 写作站、AI 搜索结果页、AI 对话分享链接，URL 中常带 `ai_outputs`、`share` 等），以及来源不明的转载。它们本身就可能含有本 skill 要避免的错误。

同一篇文章被多处转载时，记录最早、最权威的那一处。自媒体文章转述招股书的数字时，尽量回到招股书原文。

## 按章节找什么

| 章节 | 优先来源 |
|---|---|
| 工商与股权 | 国家企业信用信息公示系统；企业信息平台；上市公司看招股书"历史、重组及公司架构""主要股东" |
| 主营业务与商业模式 | 招股书"业务"章节、年报"管理层讨论与分析"；官网产品页；工商经营范围只作参考 |
| 技术与研发 | 招股书和年报中的研发投入、研发人员、知识产权；国家知识产权局专利检索；软件著作权登记；有技术报告或论文时引用原文 |
| 经营与财务 | 只用 T1：招股书、年报、中报、业绩公告。非上市公司通常没有，如实写明，不要用媒体估算的数字冒充 |
| 融资与资本 | 招股书"历史"章节；工商股东变更记录；公司或投资方官方公告；一级市场数据库（IT 桔子、烯牛等，记为 T3） |
| 团队 | 招股书"董事、监事及高级管理人员"；官网管理团队页；大学官网个人主页 |
| 市场生态与合作 | 政府、园区、高校官网的新闻；中国政府采购网和各地公共资源交易平台的中标公告；合作方上市公司的公告 |
| 风险与合规 | 裁判文书网、执行信息公开网、信用中国（行政处罚、失信）；年报风险因素；监管处罚公告；股权出质登记 |

## 按企业类型的检索顺序

**上市公司**：先读最新的年报或招股书（港交所披露易、巨潮资讯网、上交所和深交所官网、SEC EDGAR），把工商、股权、业务、财务、团队的骨架搭起来；再查最近 6–12 个月的公告；最后用网页检索补充合作、政府对接、舆情等动态。

**拟上市、新三板、发债企业**：交易所审核系统里的招股书申报稿和问询回复、全国股转系统的公开转让说明书和定期报告、债券募集说明书。

**非上市企业**：工商登记、官网、政府网站新闻、招投标、知识产权、招聘信息、权威媒体报道。

**中小微和初创企业**：信息少是正常的。重点是工商、股东、知识产权、招投标、司法风险，加上能找到的官网和本地媒体报道。

## 工具可用性

- 有工商数据或国内搜索的工具（MCP 或 API）时优先使用，它们对国内来源的覆盖比通用网页搜索好。
- 通用网页搜索对头条、雪球、政府网站的覆盖可能不足。搜不到不等于不存在：在缺口表中写明"未检索到"以及可以去哪里查。
- 遇到 PDF（招股书、年报），直接读原文，并在 `locator` 中记下页码或章节。
