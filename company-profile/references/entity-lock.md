# 主体锁定

画像报告最隐蔽的错误是写错了公司：把同名公司、子公司或品牌下另一个法人的资料混进来。读者通常发现不了，而且整段内容都会是错的。所以第一步就要锁定唯一主体，并且在采集证据时逐条核对。

## 锁定卡

写在 `entity.md` 开头：

```markdown
## 主体锁定卡

| 项目 | 内容 | 证据 |
|---|---|---|
| 登记全称 | | E001 |
| 统一社会信用代码 | | E001 |
| 曾用名 | | E001 |
| 常用简称、品牌、英文名 | | |
| 上市代码 | 无 / 02513.HK 等 | |
| 注册地 | 省市区 | E001 |
| 成立日期 | | E001 |
| 法定代表人 | | E001 |
| 企业类型、登记状态 | | E001 |

锁定依据：[如何确认的，例如"国家企业信用信息公示系统检索全称，唯一结果"]
报告用途：[通用画像 / 招商 / 投资 / 合作 / 授信 / 拜访]

### 易混淆主体

| 名称 | 关系 | 如何区分 |
|---|---|---|
| | 同名或近名 / 母公司 / 子公司 / 同品牌其他法人 | 注册地、信用代码、业务不同 |
```

## 怎么查

1. **工商登记**：国家企业信用信息公示系统、信用中国，或企查查、天眼查、爱企查、启信宝。用全称精确检索，拿到信用代码。工商数据接口（MCP 或 API）可用时优先用它。
2. **上市公司**：交易所公告中的公司全称和注册地址，与工商登记交叉核对。
3. **只给了简称**：先检索简称对应的品牌或集团，再找运营主体。上市公司以上市主体为准；未上市集团以对外签约、发布产品的主要运营主体为准，并在锁定卡中写明集团内其他重要法人。

## 怎么排查易混淆主体

- 用简称、核心字号（如"智谱"）在工商平台检索，看有没有其他企业用同样的字号。字号相同、行业不同的企业（如"智谱纳米科技（上海）"与智谱 AI）最容易被搜索结果混进来。
- 列出主要子公司和母公司。子公司的中标、专利、处罚，不能直接写成本主体的。
- 留意更名：曾用名下的资料属于本主体，但要写明当时的名称。

## 采集时怎么核对每条资料

一条资料满足以下任一项，就可以记为 `confirmed`：

- 出现完整的登记全称或信用代码；
- 出现简称，同时上下文中的业务、产品、人物、地点与锁定主体吻合，且易混淆主体表中没有同样吻合的企业。

记为 `related`：明确说的是母公司、子公司、分公司或关联方。正文引用时要写明是哪家，例如"其全资子公司××中标……"。

记为 `rejected`：说的是别家企业，或者无法判断说的是哪家。被排除的资料也记进证据库，这样之后不会再次误用。

## 常见陷阱

- 搜索结果的摘要里只有简称，打开原文才发现是另一家公司。
- 百科词条把多家同名企业合并在一个页面，或者混用了更名前后的信息。
- 企业信息平台上的"注册资本"和新闻里的数字不同：通常是增资前后的时点差异，以工商登记最新值为准，并写明时点。
- 外资、港股主体和境内运营实体（VIE 架构）不是同一法人，财务数据口径也不同。
- 知名企业常被冒用：有人伪造营业执照、冒充员工收费，或者抢注同名商标。锁定依据最好包含公司官方渠道公布的主体名称（例如官网或声明中的收款账户名、用户协议中的签约主体），而不是只看企业信息平台。
